Configuración

Correos que envía la app, IDs de los archivos y carpetas donde se guarda todo, y tipos de servicio. Los cambios se guardan en la hoja de configuración y se aplican de inmediato.

Cada correo se envía con la plantilla de KGP; aquí cambias a quién llega, quién recibe siempre copia, el asunto y el cuerpo. El diseño, el logo, la firma y el pie no cambian.

Pega el ID o el enlace completo de Drive. Antes de guardar se comprueba que el archivo o la carpeta exista y que la cuenta de la app tenga acceso. Cambiar la base de datos o una carpeta afecta a todo lo que se guarde de ahí en adelante.

Son las opciones del desplegable "Tipo de servicio" al crear o editar una cotización. El código UNSPSC se completa solo según el tipo elegido. Renombrar o eliminar un tipo no cambia las cotizaciones ya guardadas.

El número de cada código sigue la numeración desde 1 según lo que ya hay en la base de datos. Aquí puedes subir el contador: si escribes que el último usado es el 200, el siguiente código será el 201, luego el 202, etc. No se puede dejar por debajo de lo que ya existe (repetiría códigos).
